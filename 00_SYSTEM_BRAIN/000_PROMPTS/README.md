# 000_PROMPTS — Prompt hệ thống

Lưu **prompt đầu vào** đã chuẩn hóa cho các phase quan trọng (bootstrap, migration, release).

## Quy ước

- Đặt tên theo `docs/standards/CBV_PROMPT_INPUT_OUTPUT_STANDARD.md`.
- Một prompt một file; tránh chỉnh sửa triệt để prompt đã phát hành — tạo bản mới kèm version hoặc ngày.

## Đồng bộ

- Có thể trùng nội dung với `ai-runtime/prompts/` cho bản “hệ thống” sau khi đã ổn định.
